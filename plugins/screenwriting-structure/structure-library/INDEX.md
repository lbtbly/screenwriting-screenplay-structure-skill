# Structure Library — Index to 42 Screenplay Beat Maps

**What this indexes.** 42 page-referenced structural analyses, each built from the source PDF, each turn cited to a printed page and each percentage computed against that script's own measured length. Cross-script findings — tolerance bands, the late-break licence, measured page counts by format — are compiled in `../skills/story-structure/references/measured-evidence.md`. Each map carries its own verification note and its own draft-vs-release divergences in its header and final section.

**Where the files are.** Beside this index, flat: `./<file>.md`. Filenames below are bare; append `.md`.

**How to use this.** Pick a lookup route — framework (§1), format (§2), genre (§3), **structural problem (§4 — the fastest route)**, measured turn placement (§5). Read one map, not five.

## 1. By framework

**Field 3-act** — `the-matrix` cleanest measured paradigm in the set (PPI 23–24%, mid 48–50%, PPII p.95/75%) and the only one that *splits* its midpoint into an audience turn (Cypher, p.60–61) and a hero turn (the Oracle, p.73/58%) · `erin-brockovich` the same paradigm with no action engine: every act break is literally a transaction, and the protagonist is fired at ~30% so PPI is a resurrection, not a decision · `et-the-extra-terrestrial` Field beats over an eight-sequence chassis; its PPII is a death (p.98/87%) · `parasite` runs a three-act pass only to demonstrate that it hides the protagonist handoff.

**Save the Cat** — `legally-blonde` the library's canonical STC exemplar and its most instructive failure: "Bad Guys Close In" (54–83%) is a *winning streak* and All Is Lost lands at 85% · `mean-girls` 8 of 15 beats within two points, and splits Break into Two into a moral break (p.29/25%) and a mission break (p.39/33%) · `everything-everywhere-all-at-once` the most orthodox STC in the entire library — 11 of 15 within three points — proving that apparent formlessness is in the *content* of beats, not their placement · `juno` an STC quick pass laid over a four-seasons pregnancy clock, with a midpoint at 67%.

**Eight-sequence** — `et-the-extra-terrestrial` eight sequences at an unusually even 12–17 pp each, aligned to the writer's own six FADE OUT/FADE INs (pp.7, 24, 45, 68, 87, 112) · `raiders-of-the-lost-ark` sequences as a relay: one object changes hands nine times with no repeated method · `the-matrix` a third pass over an already-mapped Field/Vogler script, useful for seeing where the three lenses disagree.

**Vogler / Hero's Journey** — `dune` runs eleven of twelve stages and refuses the twelfth on the page (Paul says "No," p.109) · `mulan` the only map to run three journey frameworks at once — Vogler, Murdock, Hudson — and the demonstration that the wrong lens describes a *different character*, not merely a worse fit · `the-matrix` a clean 12-stage pass with no deviations worth arguing.

**Harmon Story Circle** — `tv-ted-lasso-pilot` a half-fit and the informative one: You/Need/Go/Search map, Find/Take/Return/Change break because the hero never states a want, so the honest reading is a half-circle welded to the antagonist's full circle · `tv-russian-doll-pilot` fits well, but the fit comes from the loop premise rather than from writing to Harmon.

**McKee** — `erin-brockovich` a dedicated progressive-complications pass (expectation vs. result, priced scene by scene) · `no-country-for-old-men` the archplot/miniplot distinction and the deliberately withheld obligatory scene · `parasite` McKee as the accurate description of the last 40 pages only · `tv-chernobyl-ep1` Mazin's central dramatic argument — theme as an arguable proposition, stated in the first line of dialogue and itemised for 53 pages.

**Miniplot / anti-plot** — `no-country-for-old-men` archplot for 85%, then miniplot for the last 15% · `aftersun` no plot at all: calendar instead of causality, with the whole act structure hidden in 4.8 pages of memory frame · `lady-bird` episodic with no goal-obstacle spine, organised by calendar, relationship curve and a repeating four-beat experiment pattern · `the-father` architecture *is* the set — five numbered décor states in one studio space.

**Kishōtenketsu** — `parasite` the only map running it, and it wins the argument: p.71 is a genuine *ten* (it voids the goal rather than escalating it, works by re-description, and the *ketsu* reconciles rather than resolves).

**Tonal-shift architecture** — `parasite` a single hinge at dead centre, prepared by fifty pages of planted objects · `tv-barry-pilot` a full register-transition ledger, alternating for four movements then fusing for two · `tv-mom-pilot` tonal switching inside multi-cam joke rhythm, with measurable hold-lengths · `tv-beef-pilot` comedy and dread carried by two mirrored protagonists rather than by alternation.

**Non-linear** — `oppenheimer` dual timeline signalled by only three things: two super titles, a colour cue on the slug, and grammatical person (Fission first-person, Fusion third) · `tv-bojack-times-arrow` subjective memory transit that runs *forward* for 32 of 39 pages and reverses exactly twice, both in the last four · `tv-this-is-us-pilot` a braid with a delayed root, held together by thematic rhyme until p.52 reveals it was genetics · `the-father` non-linearity as symptom rather than device.

**Whodunit (fair-play)** — `glass-onion` two-pass mystery with a full clue ledger; the hinge is a `HARD CUT TO:` and one mirrored slug line, nothing more · `tv-only-murders-pilot` closed-world Christie logic converted into a *serial* engine, with the corpse withheld to 43% · `tv-mare-of-easttown-ep1` a community web dense enough to hide a killer, built before any case exists.

**Howcatchem / inverted** — `tv-poker-face-pilot` the only one; a three-stage engine rather than Columbo's two (crime 9 pp → rewound run-up 22 pp → investigation), with the detective concealed inside the crime half's final image.

**Rashomon** — `tv-the-afterparty-pilot` three stacked layers of reality with an omniscient prologue as the audience's calibration instrument; two-thirds of the page count sits inside somebody's memory, and genre is the POV.

**Loop** — `tv-russian-doll-pilot` a complete iteration ledger and the counter-intuitive craft rule: the loops do not shorten, the fixed sequence *inside* them does (8.7 → 5.4 → 3.0 pp).

**Network act grid** — `tv-the-rookie-pilot` the canonical exemplar, and deliberately unequal (21/8/8/12/11) · `tv-desperate-housewives-pilot` teaser + four acts with three of four act-outs belonging to the serialized mystery · `tv-breaking-bad-pilot` cable teaser + four acts at 3/14/14/12/14, with act-outs chosen as transgressions rather than jeopardy · `tv-severance-pilot` prints network acts on a streaming show, as a drafting discipline · `tv-this-is-us-pilot` prints nothing yet infers to 8.5/9/10/9/8.3/8.1 — more regular than several scripts that do print.

**Premium continuous (no printed acts)** — `tv-succession-pilot` six movements, turns marked by location + status flip + information release simultaneously · `tv-mare-of-easttown-ep1` no acts *and* no case structure · `tv-chernobyl-ep1` a real-time clock embedded in the scene headings instead of act furniture · `tv-the-bear-pilot` the service deadline is the act structure.

**Limited series** — `tv-chernobyl-ep1` episode one under a known historical outcome · `tv-mare-of-easttown-ep1` episode one that defers its own inciting incident to the last two pages · `tv-beef-pilot` a half-hour limited opener audited against limited criteria (designed ending, no perpetual engine).

**Multi-cam** — `tv-seinfeld-pilot` two acts of exactly 22 pp, no cold open, no tag, no stand-up spine yet · `tv-big-bang-theory-pilot` the library's primary measured multi-cam sample (99 words/page, ≈2.1–2.4 pp per screen minute) with a 13-page cold open carrying the entire inciting incident · `tv-mom-pilot` two 17-page acts built in opposite directions — Act One breadth (7 scenes @2.4 pp), Act Two depth (3 scenes @5.7 pp).

**Single-cam / mockumentary** — `tv-the-office-pilot` a British single block printed inside a US pilot; 9 talking heads are 27% of scenes but 11.5% of words, and the whole series engine sits in a TAG at 97% · `tv-abbott-elementary-pilot` network mockumentary with hard printed act-outs at 35% and 71%, both of them public arguments lost rather than cliffhangers · `tv-ted-lasso-pilot` no acts at all; a turn roughly every five pages, always an information release.

**Half-hour drama** — `tv-barry-pilot` feature act positions executed at half-hour scale (31% / 49% / 71% / 86%) · `tv-the-bear-pilot` one continuous working day, process as plot, clock consulted nine times · `tv-beef-pilot` a hinged diptych measured to two decimal places (17.26 / 17.23 / 5.51 pp).

**Anthology** — `tv-black-mirror-national-anthem` dramatic anthology: no engine to install, so a single unfalsifiable demand with a deadline, and licence to destroy the protagonist and use up the world · `tv-weird-city-the-one` comic anthology whose printed acts (13/17/5) are offset from its dramatic turns throughout · `tv-bojack-times-arrow` the anthology move played inside an ongoing series — a POV episode that re-prices four seasons.

## 4. By structural problem — the fastest route

| The problem | Go to | What they actually do about it |
|---|---|---|
| My first act runs long | `glass-onion` (37–38%) · `erin-brockovich` (33–36%) · `when-harry-met-sally` (~36%) · `dune` (29–30%) | The four latest breaks in the corpus, and each runs *complete small stories* before the break — an entire fake detective story then killed, a full job-hunt with its own crisis, three separate meetings, the gom jabbar plus the departure. A long Act One is affordable when it isn't only setup. |
| My first act runs long (TV) | `tv-the-rookie-pilot` (first break 35%) · `tv-succession-pilot` (central turn 58–60%) | Rookie installs the permanent series engine on one page (the "T.O. match game," p.10, makes three mismatched two-handers in twelve lines); Succession makes every installation scene a transaction. |
| **My second act sags** | `erin-brockovich` (PPI p.48 → PPII p.110 = 62 pp, **46% of the script**) · `everything-everywhere-all-at-once` (Fun and Games 47 pp, 38%) · `dune` | Erin's second act has no duel in it — PG&E never engages — and stays alive on three supplies running at once. **(1) A referral chain instead of new scenes:** neighbours vouch for neighbours (pp.57–65 adds four families and four diseases in a page) and the count climbs 1 family → 11 people (p.67) → 100+ (p.87) → 600 (p.103) → 635. **(2) Two number ladders that cross at the midpoint:** money ($250,000 p.55 → $20M refused p.98 → $50–400M p.108) and toxicity (0.58 ppm found p.39 against a legal limit of .05, p.46) — the act's biggest reversals are ratios read aloud. **(3) A B-story that charges her for every advance:** George is childcare (p.21) before he is a boyfriend, so his exit at p.94 is a logistics crisis, and Beth's first word arrives down a phone at p.74. Its own map's verdict: **remove the personal-cost storyline and Act Two is structurally inert.** Two further props hold it up — the impossible condition is stated aloud at the midpoint ("if, and only if, you find me the evidence," p.68) so the whole act aims at a fixed target 62 pages early, and the missing clock is installed in the protagonist's body at p.85 and escalated in five coughs to collapse at p.112. EEAAO buys its long middle with a curriculum; Dune buys its passive one with the villain's plan. |
| Nothing happens in my middle | `everything-everywhere-all-at-once` (Fun and Games 47 pp / 38%) · `tv-the-bear-pilot` (pp.8–18, ~30%) · `dune` | EEAAO delivers eleven distinct rules between pp.21 and p.92 at a steady 5–8 page interval and never repeats a lesson — the audience is always being taught rather than waiting — then schedules the retraction (pp.90–91, "there is no evil villain really") so the third act cannot be won with the first act's tools. The Bear spends a third of the episode on one unbroken CONTINUOUS chain through six rooms, installing five characters, three rules, the antagonist and the business model while walking. Dune hands the audience the Baron's entire plan at pp.20–21 and seals the conspiracy at pp.42–44, 25 to 50 pages before it fires: a middle where the protagonist mostly watches reads as dread, not drift. |
| I need to change genre mid-film | `parasite` | One doorbell at p.71 (50.4%), caused by the first half, and every weapon in the last twenty pages was planted as a joke in the first fifty. |
| My genre changes and I don't know if that's allowed | `legally-blonde` (one seam, p.25/21%) · `parasite` (p.71/50.4%) · `tv-the-afterparty-pilot` | Allowed when it is staged and dated. Legally Blonde runs Rites of Passage for 25 pages — heartbreak, mourning, a grief-driven plan — and switches to Fool Triumphant the frame the Boxster hits Harvard Yard: one seam, executed as a wordless image, never revisited. Parasite's switch is caused by its own first half (the housekeeper the family got fired at p.51 is the person at the door at p.71). Afterparty makes genre a *diagnosis of the teller* — "I came for love" (p.18) selects the rom-com — and keeps it fair by leaving the distortion detectable on the page: rain that starts for the kiss (p.39) and stops when the kiss is interrupted. The test: name the page that causes the switch, and name what the new genre is *for*. |
| My protagonist dies or exits before the end | `no-country-for-old-men` (Moss killed off-screen ~p.102/87%) · `parasite` (handoff at p.89, said on the page) | Both plant the successor early — Bell narrates pp.1–3 before he owns a single scene. If the final POV hasn't spoken by the end of Act One it cannot inherit the ending. |
| I have no plot engine | `lady-bird` · `aftersun` · `tv-the-bear-pilot` · `tv-chernobyl-ep1` | Substitute a calendar (school year / holiday days), a relationship curve, an operational deadline, or a proposition with a price list. |
| I need to introduce a large ensemble fast | `tv-succession-pilot` (8 principals) · `tv-desperate-housewives-pilot` (4 co-leads) · `tv-mare-of-easttown-ep1` (43 on screen) | Succession installs the eldest son *last*, at 39%, inverting birth order; Housewives uses one repeated V.O. sentence shape at a single wake; Mare lets the town do the introducing so nobody is introduced as a suspect. |
| My mystery must survive a replay | `glass-onion` · `tv-poker-face-pilot` | Glass Onion's rewind is a `HARD CUT TO:` and a mirrored slug (black door → white door) — no device at all. Poker Face hides the detective inside the crime half's last image ("an unseen woman," p.9), converting a 22-page replay into revelation. |
| I need repetition to stay entertaining | `tv-russian-doll-pilot` | Hold the runtime, change the contents: loops stay the same length while the fixed sequence inside compresses 8.7 → 5.4 → 3.0 pp. Audience learns the rule at p.13, the protagonist at p.20. |
| My investigation scenes repeat | `erin-brockovich` (15 catalogued complications) · `glass-onion` (55 pp compressed to 24) · `tv-poker-face-pilot` | Erin's fifteen progressive complications never repeat because the gap is never about *information* — it is about status, and the escalation is carried by who the opponent sends (a squeaking mail clerk p.54 → four senior attorneys p.86 → Corbin's private plane p.107), by arithmetic, and by referral. Glass Onion spends sixteen pages of *entirely new* material (pp.73–88) before it repeats a single scene, then compresses 55 pages of Pass One into 24 — roughly 2.3:1, only about eleven scenes revisited — and re-grades the tone, so Pass One's most emotional beat (pp.39–40) becomes Pass Two's biggest laugh (pp.93–95). Poker Face literally replays only two scenes, about ninety seconds: **hide one person, not one fact.** |
| My ending arrives before my climax | `oppenheimer` | Trinity at 67% is a *physical* climax; the structural ending is cut away from at p.8 and paid at p.195, so the last Fusion line answers the first Fission scene. |
| I must make a known outcome suspenseful | `tv-chernobyl-ep1` · `dune` | Chernobyl opens on its endpoint (Legasov's suicide) and runs the audience's superior knowledge against a denial ladder that only strengthens. Dune restores suspense to a prophecy by making the two visions before the climax (pp.100, 107) flatly false. |
| My mystery has no body yet | `tv-mare-of-easttown-ep1` (real body at ~98%) · `tv-only-murders-pilot` (corpse at 43%) | Mare substitutes an emotional turn at the exact midpoint (p.30/48%, the ex is engaged). Only Murders pre-loads a flash-forward body on p.1 as insurance, buying fifteen leisurely pages. |
| My protagonist has no stated want | `tv-ted-lasso-pilot` | Dramatic irony replaces want: the sabotage reveal (p.21/54%) is placed seven pages *before* the BELIEVE sign (p.28/72%). Reversed, the sign is a slogan. |
| My protagonist is passive | `dune` (passive pp.1–76 / 0–69%) · `tv-ted-lasso-pilot` · `lady-bird` · `tv-the-afterparty-pilot` | Dune's Paul initiates perhaps five actions in 76 pages and **the father is the functional protagonist of Act Two** — it survives because the passivity is thematized (a boy asking whether his life is his own), because the audience holds the villain's plan from p.20, and because agency is handed over on the exact page the world removes everyone who was acting for him. Ted's most decisive physical act in 39 pages is hanging a poster; three systems carry the drive instead — a partner with a plan, an environment that attacks continuously, and an audience holding information he doesn't — and removing any one goes inert. Lady Bird makes one plot decision (p.14) and a dozen identity decisions: track what she pretends to be and who catches her, not what she wants. Afterparty buys agency back in eight lines at p.51. |
| My hero is passive at the climax | `raiders-of-the-lost-ark` | In this draft the Ark opens with Indy off-screen (p.94). The draft's own rebuttal is p.96 — he drags it off the island, so without him it stays buried. Read against the release cut's two added beats. |
| My act break has no cliffhanger available | `tv-abbott-elementary-pilot` · `tv-severance-pilot` · `tv-breaking-bad-pilot` | Abbott buttons on public humiliation and deliberately refuses to act-out on its biggest reversal (p.22/65%), spending two pages converting it into the hero's own mistake. Severance: three of five act-outs are stillness. Breaking Bad: three of four are transgressions, measuring appetite not danger. |
| My formal device feels imposed | `tv-bojack-times-arrow` · `the-father` · `aftersun` | Make the apparatus diegetic: BoJack's time-jump cards are books Beatrice is holding (burned on p.36); The Father's postcard at p.83 carries the p.10 kitchen poster on its reverse; Aftersun's frame is a camcorder tape being played. |
| I have two protagonists | `tv-beef-pilot` · `tv-severance-pilot` · `erin-brockovich` | BEEF splits 17.26 / 17.23 pp with a 5.51-page convergence and runs the same five-beat template twice. Severance splits one body into two characters and welds them at p.51. Erin/Ed price every turn through a recurring negotiation ritual. |
| Exposition is drowning my pilot | `tv-the-office-pilot` · `tv-desperate-housewives-pilot` · `everything-everywhere-all-at-once` | Delegate it (talking heads = 27% of scenes, 11.5% of words), ration it by rule (the dead narrator gives women's interiority and never a man's), or teach exactly one new rule every 5–8 pages and never repeat it — which is what lets Fun and Games run 47 pages. |
| I don't know where my midpoint goes | §5 of this index first · `the-matrix` · `et-the-extra-terrestrial` · `parasite` · `erin-brockovich` · `juno` | Placement first: fourteen of the seventeen features with a locatable midpoint — **82%** — land 47–55%, so put it at centre and flag it only outside that band. Then choose what kind it is. A **split**: The Matrix turns the audience at pp.60–63 (Cypher's steak deal) and the hero at p.73/58%. A **want-reversal**: "E.T. phone home" at p.62/55% flips *can he keep him* into *can he give him up*. A **voided goal**: Parasite's p.71/50.4% does not escalate the pursuit, it cancels it. A **stated condition**: Erin's p.68/50.4% — "if, and only if, you find me the evidence" — fixes the terms of a climax 62 pages early. Juno at 67% is the corpus's only real outlier, and it is paid for by a four-seasons pregnancy clock. |
| My midpoint isn't landing | `the-matrix` · `et-the-extra-terrestrial` · `lady-bird` | Split it (audience midpoint p.60–61, hero midpoint p.73/58%); make it a want-*reversal* not an escalation ("E.T. phone home" arrives at p.62/55%, flipping *can he keep him* into *can he give him up*); or change the protagonist's tribe just before centre (Lady Bird pp.50–52 / 45–47% — its map calls this "the exact centre," and on its own numbers it isn't). |
| My third act is the wrong length | `legally-blonde` (All Is Lost 85%, 12-page Act Three) · `et-the-extra-terrestrial` (Act Three 11%) · `dune` | Dune splits the Act Two curtain in half — external collapse pp.69–71 (63–65%), emotional collapse pp.82–85 (75–78%) — to run twelve pages of catastrophe without an early all-is-lost. |
| My ending doesn't feel earned | `erin-brockovich` · `oppenheimer` · `et-the-extra-terrestrial` · `tv-mare-of-easttown-ep1` | An unearned ending is almost always a condition that was never stated. Erin's climax is a *delivery* — she walks into a room and puts down a box — and all of its charge was manufactured fifty pages earlier by naming the impossible conditions out loud: "if, and only if, you find me the evidence" (p.68) and "show me the document that proves that" (p.81), answered by 635 signatures and a memo stamped March 1966 (pp.130, 129). Oppenheimer tells the audience at 4% that a conversation exists (pp.7–8), refuses it repeatedly, and plays it as the last scene of the film (pp.195–197). E.T. plants its final line at p.31/27% in the wrong character's mouth. Mare completes the victim's triangle — threat and motive included — by p.14/21% and lands the body at ~98%, so the reveal costs zero exposition and reads as recognition. |
| My comedy has to carry real pain | `tv-mom-pilot` · `tv-barry-pilot` · `tv-beef-pilot` | Mom sets explicit hold-and-release rules for tonal switches inside multi-cam joke rhythm; Barry runs two climaxes back to back (acting p.31–33, killing p.34) so the second answers the first. |
| My twist has to be fair | `tv-this-is-us-pilot` · `glass-onion` · `tv-the-afterparty-pilot` | This Is Us parks the reveal 13 pages *after* the last act break and 1.5 before the end, refusing the obvious act-out slot. Glass Onion and Afterparty both carry full clue ledgers, Afterparty with reliability tiers. |
| I need a closed world / bottle | `tv-only-murders-pilot` (one building) · `the-father` (one studio space, five décor states) · `glass-onion` (one island) | Bounded suspect pool as a serial engine; a mutating single set as the whole architecture. |

## 6. How to read a map

**Anatomy.** Every file opens with a metadata line (source PDF, writer, format, genre, measured length, draft identification, and the PDF-to-printed page offset), then Logline → **Structure overview** (a block table plus the located turns — this is usually all you need) → Beat map (page / % / beat / what happens / notes, one row per beat) → one or more framework-pass tables (`Framework × Beat × Page × Variance`) → Storylines → Structural devices → Deviations & tensions → Lessons for the knowledge base. Page citations are the script's own **printed** page numbers, not PDF pages, and every percentage is computed against that script's measured length rather than an assumed 110. If a map needs a different convention (OCR'd source, A-pages, physical-vs-printed pagination) it says so in its own header — read those four lines before quoting anything.

**The standing caveat.** *Every map is of the draft in the library, and that draft is frequently not the release cut.* Several are materially different works: Severance's protagonist is Mark, not Helly, with no Lumon and no Petey; Succession's Kendall *wins* the deal; Barry kills NoHo Hank on p.34; Legally Blonde has no graduation ending; Seinfeld's Elaine is "Eileen" and there is no coffee shop; Raiders opens the Ark with Indy off-screen and contains a Shanghai sequence later recycled into *Temple of Doom*; BoJack's celebrated visual devices postdate this table draft; Abbott Elementary is titled *Harrity Elementary*. Each file logs its own divergences in its header and its closing section, and reading those logs across the corpus is the cheapest available lesson in what rewriting is for, since in nine of those cases the draft-to-screen change is structural rather than a dialogue polish. One known source defect: the No Country PDF is an 8-page excerpt, so that map's pp.83–110 are interpolated and marked `~est.` (treat as ±2).
